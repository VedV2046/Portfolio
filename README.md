# 🌐 Ved Vharamble — Portfolio

A personal portfolio website built with React and Vite, showcasing my projects, skills, and journey as an Electronics & Telecommunication Engineering student and web developer.

🔗 **Live Site:** [portfolio-ved-vharamble.vercel.app](https://portfolio-ved-vharamble.vercel.app)

---

## ✨ Features

- ⚡ Fast and optimized build with Vite
- 🎬 Smooth animations powered by Framer Motion and custom Reactbits components
- 📊 Vercel Analytics for visitor tracking
- 💡 Animated loader screen with percentage counter
- 📱 Fully responsive across all screen sizes
- 🎨 Dark theme with charcoal + violet accent palette
- 🧩 Modular component architecture

---

## 📁 Sections

| Section | Description |
|---|---|
| **Home** | Animated hero with name, title and intro |
| **About** | Bio, profile card and personal summary |
| **Tech Stack** | Logo loop of tools and technologies |
| **Journey** | Timeline of academic and project milestones |
| **Work** | Featured projects with descriptions and links |
| **Contact** | Contact form and social links |

---

## 🛠️ Tech Stack

- **Framework:** React 18
- **Build Tool:** Vite
- **Animations:** Framer Motion, custom Reactbits components
- **Styling:** Plain CSS (modular per component)
- **Deployment:** Vercel
- **Analytics:** Vercel Analytics

## 🏃 Running Locally

```bash
# Clone the repo
git clone https://github.com/VedV2046/Portfolio.git

# Navigate to the project
cd Portfolio/Portfolio

# Install dependencies
npm install

# Start dev server
npm run dev
```

---

## 📦 Building for Production

```bash
npm run build
```

Output goes to the `dist/` folder. Deployed automatically to Vercel on every push to `master`.
